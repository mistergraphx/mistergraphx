# Arnaud Bérard

**Développeur front-end et intégrateur indépendant depuis 2010** · Accessibilité, performance, éco-conception

Je construis des sites rapides, accessibles et durables pour des médias, des agences et des grands comptes, de la maquette Figma jusqu'à l'intégration finale. Graphiste print de formation, je tiens à ce que l'intégration reste fidèle à l'intention du design.

### Ce que je fais aujourd'hui

- **Architecture CSS et design systems** : utility-first, SCSS en modules, variables CSS pensées pour les thèmes (dark mode, taille du texte)
- **Performance web et éco-conception** : poids des pages, scripts tiers, suivi en CI/CD
- **Accessibilité côté intégration** : sémantique HTML, navigation au clavier, contrastes, textes alternatifs
- **WordPress sur mesure** : thèmes multilingues, ACF Pro, layouts flexibles
- **Maintenance et évolution de sites** pour des TPE et PME

**Stack** : HTML · CSS / SCSS · JavaScript · TypeScript · PHP · WordPress · SPIP · Twig / Nunjucks · Node.js
